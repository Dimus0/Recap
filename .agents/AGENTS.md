# 🤖 Project Rules & Workflow Guidelines (Recap Project)

## 📌 Token Saving & Project Context Protocol

На початку кожного запиту (промпту) від користувача:
1. **Прочитай `PROJECT_INDEX.md`**: Відкрий [PROJECT_INDEX.md](file:///e:/personalproject/recap-project/PROJECT_INDEX.md) та ознайомся з актуальною структурою проекту, картами файлів, моделями даних та останніми змінами. Це дозволяє уникнути повного повторного обходу всіх файлів репозиторію та економить токени.
2. **Точковий пошук та внесення змін**: На основі карти файлів переходь безпосередньо до потрібних файлів, які необхідно створити чи модифікувати.
3. **Обов'язкове оновлення `PROJECT_INDEX.md` після виконання завдання**:
   - Онови розділ з картою файлів/структурою (якщо були додані, видалені чи перейменовані файли).
   - Запиши нову строчку у таблицю **Журнал змін (Changelog)** у [PROJECT_INDEX.md](file:///e:/personalproject/recap-project/PROJECT_INDEX.md) із зазначенням поточної дати (`YYYY-MM-DD`), списку змінених файлів та короткого опису внесених змін.
